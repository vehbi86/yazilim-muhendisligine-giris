# Yazılım Mühendisliğine Giriş

14 haftalık ders programı ve haftalık sunumlar.

## Dersin amacı

Yazılım mühendisliğinin temel kavramlarını, yazılım geliştirme süreçlerini ve ekip çalışmasının temel uygulamalarını tanımak.

## Sunum yükleme

1. İlgili haftanın **Sunumlar** bağlantısını açın.
2. **Add file → Upload files** seçeneğini kullanın.
3. Sunum dosyanızı seçip **Commit changes** ile kaydedin.

Sunumlar eklendikçe ilgili haftanın klasöründe görüntülenir. Haftalık konu başlıkları dersin ilerleyişine göre güncellenebilir.
